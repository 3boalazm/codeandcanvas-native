## 0. الفرع والحالة الأساسية

- الفرع: `arena/5f16dd5e-codeandcanvas-native` من `main` (19e95fb).
- قبل أي تغيير: `npm run check` ناجح (41 صفحة chrome متزامنة · 42 HTML · 48 مخرج توليد مطابق).
- المعاينة: `npm run dev` → http://localhost:3000 (bind 0.0.0.0).
- لقطات خط الأساس: `docs/next-round/evidence/baseline/` (EN/AR × 1440/390، الصفحات الرئيسية).
- الاختبارات تُشغّل على Chromium محلي (`PW_EXECUTABLE_PATH` + `LD_LIBRARY_PATH`)، APIs محاكاة، لا إرسال حقيقي.

## 3. التواريخ والأرقام والادعاءات

- لا إضافة رقم جديد بلا مصدر؛ الأرقام الحالية تبقى منسوبة صراحةً إلى عرض خبرة المؤسس.
- «Proven Results» و«Real Projects» تُستبدل بصياغة تصف المخرجات المتوفرة لا النتائج التجارية.
- رسوم النطاق تبقى معلّمة: رسم توضيحي لا لقطة منتج ولا إثبات نتيجة.
- بوابات المالك (صور، شهادات، حقوق، قانون، ERP) تبقى كما في `docs/ASSET-AND-CLAIM-REGISTER.md` ولا تُغلق محليًا.

## 4. العربية المستقلة (المرحلة E)

- استراتيجية URL: `/ar/<route>/` مولّدة من الصفحات الإنجليزية بعد sync-chrome، مع `canonical` ذاتي و`hreflang` متبادل و`x-default`.
- العربية HTML فعلية في الملف (بدون JS): النص العربي يصبح المحتوى، والإنجليزي ينتقل إلى `data-en*`، و`site.js` يحترم `data-locale`.
- المسارات التشغيلية (`/account/`, `/cart/`, `/login/`…) تُولَّد عربية أيضًا لكن تبقى `noindex, follow`.
- التوسيع يشمل `manus-routes.json`، `sitemap.xml` بـ`xhtml:link`، واختبار المصفوفة.
