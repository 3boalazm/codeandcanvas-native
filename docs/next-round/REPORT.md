## 2) الطبقة الثانية — هندسة محلية (مكتملة لهذه الجولة)

- **خط التوليد**: `npm run generate` = `gen-pages.py` → `sync-chrome.mjs` → **`gen-ar.mjs` (جديد)**.
- **`scripts/lib/arize.mjs` (جديد)**: تحويل زمن بناء لصفحة إنجليزية منتهية إلى توأم عربي مستقل:
  الستّ صيغ (`data-ar`, `data-ar-html`, `data-ar-label`, `data-ar-title`, `data-ar-alt`, `data-ar-placeholder`)،
  إعادة بناء `.split` ككلمات متحركة، تعريب `title/description/og/JSON-LD`، canonical ذاتي، وhreflang متبادل + `x-default`،
  وتحويل زر اللغة إلى **رابط حقيقي** إلى النسخة الإنجليزية.
- **تنقّل اللغة بالعنوان**: `<html data-lang-mirror="/ar/…">`، فينتقل الزر إلى التوأم العربي (والعكس) مع الحفاظ على الاستعلام
  (`/contact/?inquiry=HC-03` ⇄ `/ar/contact/?inquiry=HC-03`)، ويبقى `?lang=ar` يعمل بالتبديل الفوري كما كان.
- **قفل اللغة**: `assets/js/site.js` يحترم `data-lang-lock`، فلا يمكن أن تقلب `?lang=en` أو `navigator.language` صفحة عربية.
- **`sync-chrome.mjs`** يتجاوز `ar/` (مخرَج مشتقّ)، و**`check-generated.mjs`** يعيد توليد العربية معزولة → 91 مخرجًا متطابقًا.
- **`sitemap.xml`** يحمل بدائل xhtml لكل عنوان (en/ar/x-default)، مع حذف توائم المقالات غير المترجمة.
- **`manus-routes.json`** يحمل مسارات `/ar/…` بوسم `lang:"ar"`، فغطّاها الاختبار المصفوفي تلقائيًا.

### الأخطاء التي وُجدت وأُصلحت في القواعد المالكة (لا في طبقة تعليق فوقها)
1. `.reader__parts button.is-locked { opacity:.5 }` في `pages.css` كان يخفض تباين النص إلى **2.84:1**
   (فشل `axe /books/marketing-fundamentals/read/`). الحل: إزالة الشفافية، لون `--ink-3`، ونقطة قفل ذهبية + بديل نصي لغير البصر.
2. روابط الموافقة في `/checkout/` (عربي) كانت تفشل `link-in-text-block` (1.1:1 بلا تسطير) → قاعدة تسطير في `ds.css`.
3. تعارض كلاس قديم `.cs` مع قسم الأعمال الجديد (كان يقصّ العمود إلى 231px) → إعادة تسمية القسم + حذف القواعد الميتة.
4. 7 أخطاء `</p>` ناتجة عن وسوم خام داخل `data-ar-html` → ترميز الكيانات في المولّدات.
