06HOW WE WORK

Written scope. Clear milestones.

Invoicing doesn’t start before the scope is written, and the scope never changes without a quote first. This is the same cycle on every engagement — from one call to the final file hand-over.

The full methodology
01

Scope before money

One call, then a written proposal: the outcome, the deliverables, the duration, the price range and what is explicitly out of scope.

Fixed-scope proposal
02

Build in milestones

Delivery runs in stages, each with a review and an acceptance gate. Any change request is quoted before it starts and never added to an invoice quietly.

Review at every gate
03

Hand-over you own

Source files, code and documentation are released when the final milestone closes. No lock-in, no dependency holding your work hostage.
