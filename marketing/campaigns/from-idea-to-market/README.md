# «من فكرة لمنتج» — Campaign Kit

**Code & Canvas · 5 posts · Facebook + Instagram · AR (Egyptian) + EN · 2026**

حملة سوشيال ميديا كاملة، مبنيّة على هوية الاستوديو الحقيقية (نفس الألوان، نفس الخطوط، نفس اللوجو) وعلى
محتوى الموقع الفعلي (المنهجية، حالة Pharmacy OS، وجلسة الـ30 دقيقة).

| الملف | إيه اللي فيه |
| --- | --- |
| `index.html` | **لوحة الكامبين** — افتحها الأول: الفكرة، قوس الحملة، الـ5 بوستات بالكوبي (عربي/إنجليزي) وأزرار نسخ، الجدول، وشيك ليست النشر |
| `captions.md` | نسخة نصية من الكوبي كله + Alt text + كومنت أول لكل بوست (للفريق أو للأرشفة) |
| `assets/feed/01–05.png` | تصميمات الفيد **1080×1350** (فيسبوك + إنستجرام) |
| `assets/story/01–05.png` | تصميمات الستوري **1080×1920** — نفس القوس + اقتباس إضافي |
| `assets/brand/logo-white-h.png` | اللوجو البيضاء (مُصدَّرة من `assets/brand/logo-white-horizontal.svg`) |
| `assets/brand/fonts/` | Alexandria (VF) + IBM Plex Sans Arabic — بترخيص OFL، النصوص موجودة جنبها |
| `render.py` | مولّد التصميمات (نفس نظام الهوية) |
| `typeset.py` | مُشكّل النص: HarfBuzz + FreeType — عشان العربي يتكتب صح (GSUB، لام-ألف، bidi للنص المختلط) |

## إعادة التوليد

```sh
python3 -m pip install --user pillow numpy fonttools brotli uharfbuzz freetype-py

python3 marketing/campaigns/from-idea-to-market/render.py          # الـ10 صور
python3 marketing/campaigns/from-idea-to-market/render.py feed     # الفيد بس
python3 marketing/campaigns/from-idea-to-market/render.py story 3  # ستوري البوست 3 بس
```

اللوجو داخل التصميم بيتصدّر من الـSVG الأصلي (مرة واحدة، لو الـSVG اتغيّر):

```sh
npx -y -p @resvg/resvg-js node -e "…"   # أو استخدم make-og.mjs كمرجع
```

## تعديل الكوبي

كل نص التصميمات موجود في `render.py` داخل `SERIES` (العنوان، السطر التوضيحي، الترجة الإنجليزية،
والاقتباس الخاص بالستوري) + `QUESTIONS` + `MODULES`.
**مهم:** نصوص الكابشن في `index.html` / `captions.md` منفصلة — لو غيّرت عنوان في التصميم، غيّر الكابشن معاه.

## نظام التصميم المستخدم

- **الخلفية:** كحلي `#00001E` + جلو بنفسجي/فيروزي/وردي + جريد 90px + حبيبات فيلم + إطار هايرلاين بزوايا.
- **العناوين:** Alexandria 800 — والنص: IBM Plex Sans Arabic (400/500/600).
- **اللاتيني:** Signate Grotesk / Poppins / Raleway (نفس خطوط الموقع).
- **التدرج:** `#3FD6C4 → #8B6CFF → #EE5BA3` — وبيتطبق على **عرض السطر نفسه**، مش على عرض الكانفس.
- **التوكنز:** رقم البوست (01/05) شمال فوق، البيل (الحقيقة الأولى / THE GAP) يمين، وخمس نقط تحت بتوضح موقع البوست في السلسلة.

## ملاحظات نشر

- المقاسات: فيد 1080×1350 (4:5)، ستوري 1080×1920. مفيش نصوص في آخر 250px تحت في الستوري (منطقة واجهة إنستجرام).
- إنستجرام: مفيش لينكات في الكابشن. فيسبوك: اللينك مباشر.
- البوست 3 (5 أسئلة) هو الأقوى للـSaves — لو الحملة كلها هتاخد Boost، يبقى ده.
- الأرقام والوعود في الحملة مأخوذة من الموقع: 14 موديول في Pharmacy OS، وجلسة تشخيص 30 دقيقة مجانية.
  **لو حصل تغيير في العرض أو الأرقام، حدّثها هنا وفي الموقع في نفس الوقت.**
- مفيش في الحملة أي شاشة عميل أو رقم مبيعات — وده مقصود: نفس سياسة النشر في `/case-studies/`.
