A bilingual brand system that scales

01THE CASE STRUCTURE

Every project is told with the same honesty.

Problem, strategy, our role, execution and an outcome that states exactly what is — and is not — proven.

01 · PROBLEM

The problem

A growing organization commissions a logo, then social posts, then a website, then packaging — each from a different supplier. Two years later the same brand looks like four different companies.

02 · STRATEGY

The strategy

Define the position and the naming logic first; derive a bilingual lockup, a colour/type system and a reusable component library from those decisions — not the other way round.

03 · OUR ROLE

Our role

Studio concept: positioning framework, identity architecture, bilingual typography rules, governance model for future suppliers.

02EXECUTION

The steps that actually ship.

Concrete deliverables, not adjectives. Each line is something a client can open, review and keep.

Execution steps

  • Audit every existing touchpoint and classify what must stay, change or disappear
  • Build the Arabic and English wordmarks on one geometric grid so neither is a stretched translation
  • Express colour, spacing and type as tokens, then apply them to print, web and motion
  • Write a short governance guide: who may change what, and how new assets get approved

What you keep

  • Positioning brief
  • Bilingual lockup
  • Token library
  • Governance guide
