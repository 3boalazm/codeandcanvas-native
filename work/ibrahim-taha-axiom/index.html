01WHAT THE WORK HAD TO SOLVE

The problem, first. Then the decision.

Why the project exists, the approach taken, and the part the founder actually played.

PROBLEM

An academic profile mixes incomparable platform counters, unsourced claims and a temptation to present simulations as published results.

APPROACH

Content counts are generated from approved data, reference templates stay read-only, and each metric carries its source, retrieval date and a plain-language definition.

ROLE

Designed and built by Mustafa Aboalazm. This page documents the publicly visible product and its source; it does not claim a studio engagement, a team, or a commercial result.

02WHAT WAS BUILT

Concrete deliverables. Not adjectives.

Each line is something a reader can open, check or keep.

BUILD
  1. A bilingual EN/AR site with research areas, publications and academic profiles.
  2. A knowledge graph linking areas, methods, publications and projects.
  3. Sourced metric panels that explain what each platform counter actually counts.
  4. An interactive normal-distribution lab and a multicollinearity experiment with explicit limits.
STACK & DISCIPLINE
  • Static site
  • Generated inventories
  • Bilingual EN/AR
  • SVG / canvas charts
